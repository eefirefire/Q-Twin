Week 3 Task 1 -- Stage 0 Chip Quality Gatekeeper
============================================================

HONEST CAVEAT on the 100% accuracy below: this isn't a hard
classification problem and the perfect score shouldn't be read as
evidence of a sophisticated model. Two reasons:
  1. DIVERGENT_REPLICATES is constructed directly from the same
     concordance status used as the 'is_divergent' feature -- that
     class is caught by definition, not learned.
  2. early_displacement_30s correlates 0.9997 with delta_f_probe
     (the quantity that literally defines SUCCESS/FAILURE via the
     -0.5 Hz threshold, see Week 1). Only 0 of 26 non-divergent
     validation chips sit anywhere near that boundary (within 2 Hz),
     so a threshold-like classifier separating them cleanly is the
     EXPECTED outcome given how strong that biomarker already was,
     not a surprising result. Real-world performance on chips closer
     to the boundary is genuinely untested here.
