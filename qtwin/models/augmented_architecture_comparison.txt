NOTE on the 'LSTM (baseline)' row: this is a fresh training run within this
script's own three-way sweep (same architecture/training-set/tuning as any
other plain-LSTM run, different RNG seed/consumption order), not a claim
about the officially-promoted model, which is TCN, not LSTM -- see
tcn_official_metrics.txt for that artifact's own dedicated numbers.

No architecture in this comparison clearly beats the officially-promoted
TCN (promoted, standalone run) on both metrics simultaneously, given this hold-out
set's small n=11 (each chip is ~9% of the reported accuracy) -- ties and
single-metric edges are within this project's known run-to-run margin.

n=11 hold-out and n=33 real validation are both small -- treat every
number here as having real sampling noise, especially any single-chip
swing on the hold-out set. HONEST METHODOLOGY NOTE (same as
model_trainer_augmented.py / lstm_augmented_metrics.txt): reporting
hold-out numbers as part of an architecture-selection decision means this
hold-out set is no longer fully untouched by downstream choices.
